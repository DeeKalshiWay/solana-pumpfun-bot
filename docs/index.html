What it does

Autonomous trading bot for the Solana pump.fun ecosystem. Detects new token launches via single-shared PumpPortal WebSocket, scores them across four factors, sizes positions adaptively based on rolling win rate, and exits via a moonshot-optimized take-profit ladder with adaptive trailing stops. Captures power-law winners while capping individual losses at -10%.

Built end-to-end in async Python. ~5,000 lines, fourteen modules, single developer.

Where the edge comes from

1. ADAPTIVE POSITION SIZING (KELLY-LITE)

Rolling 20-trade win rate scales position size: 0.6× when cold (≤30% WR), 1.0× normal, 2.0× when hot (≥55% WR). Captures more SOL during momentum stretches, less during regime shifts. Hard cap at 2.5× to prevent ruin.

2. MOONSHOT-OPTIMIZED TAKE-PROFIT LADDER

Sells small slices at +75% / +300% / +800%, keeps final 30% riding the trailing stop with no upper cap. Trailing widens to 35% from peak once peak exceeds +100% so power-law winners aren't clipped on normal pullbacks.

3. COUNTERFACTUAL LEARNING LOOP

Every rejected token gets re-polled 10 min later for market-cap delta. After 8,442 resolved outcomes across 15+ filter classes, every filter shows strongly negative average outcome on rejects (e.g. score_band_10 avg −49.5%, whale_init avg −27%, sym_blacklist_TEST 100% rug rate). The strategy is validated, not assumed.

4. CIRCUIT BREAKERS

Three independent layers: 6 consecutive losses → 10 min pause, −25% day → halt until UTC midnight, −40% lifetime → emergency stop. Fired 5 times overnight, each preventing what would have been deeper losses during regime shifts.

Production reliability

  • Single-instance enforcement via PID lockfile — duplicate launches refuse with exit code 2
  • Atomic JSON writes (write-temp + os.replace) so file corruption is impossible mid-crash
  • Watchdog auto-restart with exponential backoff on rapid crashes
  • WS rate-limit handling — exponential backoff up to 5 min on HTTP 403
  • Log rotation with gzip (20 MB threshold, 5-rotation ceiling)
  • Counterfactual file auto-trim at 5 MB to bound disk usage
  • Crash-safe state — closed trades, creator leaderboard, paper wallet all persist
Performance disclaimer: these are paper-trading results. Live trading diverges 30–50% due to real slippage (5–30% per round-trip on volatile pump.fun tokens), public-RPC latency (1–3s), MEV bots front-running, and tx failure rates. Realistic live-vs-paper retention: ~50% of paper EV. Never trade money you cannot afford to lose. Pump.fun has >95% rug rate.
